# Projects

I am working / have worked on several projects, some of which have been mentioned here:

- [Crossy Road 2D using Godot Engine](https://github.com/uttiyapal/Crossy-Road-2D): A 2D pixel-art game inspired by Crossy Road, developed using the Godot Engine and GDScript as an educational project. Players must guide the chicken across the map while avoiding vehicles, trains, and other hazards to reach the finish safely.

- [Jungle Crawler Platformer Game](https://github.com/uttiyapal/Jungle-Crawler-Game): A 2D pixel-art platformer game developed on the Godot Engine using GDScript. Players must navigate hazardous levels, collect valuable items, defeat enemies, and reach the exit while managing health, lives, and equipment. The game has been deployed on the web, and you can play it [here](https://uttiya.itch.io/jungle-crawler) on Itch.

- [GIS-based environmental analysis](https://scholar.google.com)

- [Remote sensing applications in coastal environments](https://scholar.google.com)

A more comprehensive list of my publicly available projects can be found on my [Github Page](https://github.com/uttiyapal).
